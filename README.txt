KULSOOM ZEHRA — PORTFOLIO 2026

Files:
- index.html: website content
- style.css: layout, colors, and responsive design

How to run:
1. Keep index.html and style.css in the same folder.
2. Put your images in that folder if you want to use them.
3. Double-click index.html to preview it in your browser.

Personalize before publishing:
- Replace the profile placeholder in index.html with your photo.
- Add certificate names, dates, certificate images/PDFs, and real credential URLs.
- Check every project repository link and add live demo links if available.
- If a project is still in progress, label it "In progress" rather than implying it is complete.
- Update the skills list so it only includes technologies you can comfortably discuss.

To add your photo:
Replace the profile-placeholder div in index.html with:
<img src="kuls-photo.png" alt="Kulsoom Zehra">
Then place your image file named kuls-photo.png beside index.html.
